\begin{abstract}
This compendium provides the complete, unabridged set of 10 empirical benchmark tables produced during the comparative evaluation of Abstract Syntax Tree (AST) chunking versus sliding-window line chunking in Retrieval-Augmented Generation (RAG) for source code. Every table is paired with concise empirical takeaways, methodological commentary, and statistical decisions specifically prepared for in-depth empirical evaluation and scientific reporting. All figures and tables are generated strictly via automated scripts governed by zero-hardcoding standards.
\end{abstract}

\noindent\textbf{Empirical Findings \& Methodological Takeaways (Table IV):}
\begin{itemize}[nosep,topsep=2pt,partopsep=0pt,itemsep=2pt]
    \item \textbf{Comp 1 (Pre-registered Primary Hypothesis):} AST+Header vs. Line No-Header shows $\Delta = -0.0930$ (95\% CI [-0.164, -0.023], $p_{\mathrm{raw}} = 0.0219$, $p_{\mathrm{Holm}} = 0.0438$, $W = 78.0$). The pre-registered primary comparison is statistically significant, favoring Line No-Header.
    \item \textbf{Comp 2 (Pure Chunking):} In the absence of context headers, AST chunking is statistically inferior to line chunking ($\Delta = -0.2390$, $p_{\mathrm{Holm}} < 0.001$, $W = 3.0$).
    \item \textbf{Comp 3 (Header on AST):} Adding structural context headers to AST chunks produces a large, highly significant performance boost ($\Delta = +0.1459$, $p_{\mathrm{Holm}} = 0.0001$, $W = 24.0$, 23 wins vs. 2 losses).
    \item \textbf{Comp 4 (Header on Line):} Adding headers to line chunks produces a non-significant change ($\Delta = +0.0409$, $p_{\mathrm{Holm}} = 0.2411$, $W = 118.0$).
    \item \textbf{Comp 5 (Exploratory Contrast):} Comparing the two header-equipped systems reveals Line With-Header leads AST With-Header by 0.1339 ($p_{\mathrm{raw}} = 0.0003$, 95\% CI [-0.199, -0.070], $W = 36.0$).
\end{itemize}
